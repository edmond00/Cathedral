OVERALL COMMENTS :
- most new verbs rely on new features that need to be implemented along the verb itself
- use this new verbs and related elements to each location richer (more things to do) but also more random (more differences between 2 villages or 2 forests...)
- succeeding any VERB should now grant a modus mentis. Also true for the old verbs. You can create new modus mentis to satisfy this constraint. Good modus mentis design are modus mentis that can be apllied in multiple description and to witch you can link a strong persona.
- dialogue also need to grant modus mentis :
    - the "met" action that trigger the dialogue can just grant the SOCIAL INTERACTION modus mentis
    - then each dialogue can grant different kind of modus mentis, for example BEG FOR COIN dialogue tree -> begging modus mentis
- good design for observables elements in the locations are elements that are associated to multiple verbs. For example, a flower that can be smelt, examine, contemplate, grab, ...
- at least 50% of the observables elements of the game should have at least 3 related verbs
- at least 80% of the observables elements of the game should have at least 2 related verbs
