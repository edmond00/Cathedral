The modi mentis' global LLM instructions were rewritten one change at a time against the shipped model (Qwen2.5-3B Q4_K_M, 4 CPU cores, the game's sampling). Each change was kept only if it won a blind same-sheet comparison with the old wording. Five changes were kept and fifteen lost; all are listed in tools/prompts/NOTES.md.

  • Fidelity, overall: flat. 0.72 → 0.72 on 138 samples a side. Dev rose from 0.69 to 0.72; the held-out playthroughs fell from 0.80 to 0.70 (22 cases, within the noise, shown as measured).
  • Targeted faults fixed. A person named in a reasoning: fidelity 0.60 → 0.92, gender errors 5 → 0. A lesson lost: 45% → 34% (124 a side). The style clause the model copied word for word is removed.
  • Cheaper. The user message is 239 → 221 tokens and wall time per request 9.2 s → 8.6 s (−6%), measured with a warm prefix and alternating order.
  • Item-use critic: 83.6% → 92.1% on dev, 78.0% → 85.0% held out. The ChoiceJudge was not changed (95.9%): its errors are in persona descriptions, which were out of scope.

In the cases below, the old wording is the commit the branch started from (ac61b8e). "New is worse" marks cases whose mean fidelity, or persona at equal fidelity, fell; there are many because a single prompt scores 0 to 2 across seeds.
