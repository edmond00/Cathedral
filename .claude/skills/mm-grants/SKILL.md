# The modus mentis grant audit

Produces `mm_grants.csv` at the repo root: **one row per (verb, modus mentis, context)**, written by
reading the code rather than by running it.

| column | |
|---|---|
| `VERB` | the verb id — `examine`, `mine`, `beg_for_coin` |
| `MM` | the modus mentis id it teaches |
| `CONTEXT` | free prose: **when** that verb teaches that lesson |

Three columns and nothing else. Extra columns crowd out the only one that carries judgement.

## Why this is a skill and not a `--flag`

It used to be generated by a sweep (`--mm-grant-csv`, removed). The sweep could only see what a verb
*declared* against a target it could enumerate, and a verb's lessons are free C# inside
`Verb.Lessons`. Two consequences the generated file could not survive:

- it labelled everything it could not see `not-taught-by-any-verb`, which read as dead content and
  was wrong about 111 of 167 rows;
- it reported `vigor` as reachable for a fortnight after `get_up` had silently stopped teaching it.

A person reading `Lessons` sees the whole method, including the fallthrough. The trade is that this
file is only as fresh as its last run — say so in the closing message, with the date.

## The one method to read

Each verb has exactly one, returning **ordered candidates**; the first the acting body can hold is
what gets granted:

```csharp
public override IEnumerable<ModusMentis> Lessons(LessonContext ctx)
{
    if (ctx.Night) yield return Mm<MoonwaterModusMentis>();
    foreach (var m in base.Lessons(ctx)) yield return m;   // declaration, then natation
}
```

Read the **whole** method. `base.Lessons(ctx)` yields the target's own `VerbModiMentis` declaration
and then the verb's `GrantedModusMentisIds` default — so a verb whose branches all fire
unconditionally has a default that can never be reached, and that is a finding, not a row.

`LessonContext` is what a branch may ask about: `Target`, `Night`, `IsPrivate`, `Outdoors`,
`Hostile`, `CompanionHere`, `Watched`, `TargetIsPerson`, `TargetIsHostile`, `Named(...)`. It
deliberately carries **nothing mechanical** — no difficulty, no dice, no party size.

## Where the other lessons live

1. **`Verb.Lessons`** — above. The interesting one.
2. **`IVerbModusMentisSource`** — a target's own declaration. Two implementers: `PointOfInterest`
   (declared across `src/game/scene/**`) and `NpcArchetype` (a person teaches `physiognomy` and
   `hearkening`; every other creature the naturalist's set).
3. **`Verb.GrantedModusMentisIds`** — the verb's default. Where a verb names two they are a
   **beast/human pair**; say so: *"a beast; a person falls through to X"*.
4. **`DialogueTree.GrantedModusMentisId`** and **`AdditionalGrantedModusMentisIds(npc, resolution)`**
   in `src/game/dialogue/tree/trees/`. The second is per-branch and per-person — exactly what
   `CONTEXT` is for. `CaughtRedHandedTreeFactory` is built by a factory and is **not** in
   `DialogueTreeRegistry`.
5. **`FirstBlow`** — `attack` teaches the fighting skill of the blow it drew, so it declares nothing.
   One row, context `"per blow: the fighting skill of the medium drawn"`.

## Content kinds are types

A condition names a kind by **type**, not by string:

```csharp
if (ctx.Target is CorpsePointOfInterest) yield return Mm<GravesightModusMentis>();
```

`src/game/scene/PoiKinds.cs` holds ~107 of them, each fixing a `Lemma` derived from its class name.
Where a branch still uses `ctx.Named("cave", "moor")` it is matching an **area** or prose, because
areas have not been converted — flag those, they are the remaining soft spot.

## Procedure

1. `grep -rn "Lessons(LessonContext" src/game/scene/verbs/` and read every hit in full.
2. `grep -rn "VerbModiMentis" src/game/scene src/game/npc` for the target declarations. **Group
   these**: 150 objects declaring `examine → metalcraft` is one row whose context names the kind of
   object, not 150 rows.
3. Read every tree in `src/game/dialogue/tree/trees/`.
4. Write the CSV, sorted by `VERB` then `MM`.
5. Report the row count, the verbs that teach only one thing, and anything that looked wrong.

## Writing the context column

Prose for a person deciding whether the design is right. Say **when**, in the game's own terms:

```csv
VERB,MM,CONTEXT
examine,gut_feeling,something hostile is within earshot but not visible
examine,sky_reading,at night and out of doors — beats the object's own lesson
examine,gravesight,the target is a corpse
examine,metalcraft,"declared by forge objects: anvil, bellows, quench trough"
examine,scrutiny,the default when nothing above matched
mine,veinsight,"the verb's own lesson: reading a seam, not the mason's stonework"
mine,gold_fever,the target or room is named for gold
smell,scenting,a beast's lesson — a person falls through to keen_nose
beg_for_coin,humility,"the branch lesson when begging somebody with authority; a farmhand teaches weeping"
attack,(per blow),the fighting skill FirstBlow drew — declared nowhere
```

- **Name the condition, not the code.** "at night and out of doors", not `ctx.Night && ctx.Outdoors`.
- **Say when a lesson displaces another** — `Lessons` yields in order, so an early branch hides the
  object's own declaration. That is the fact most likely to be a mistake.
- **One row per distinct reason.** Quote any field containing a comma.

## What to flag in the closing message

- a branch that fires on almost every use of its verb — it hides the object's own lesson;
- a verb whose branches never fall through to `base.Lessons`, making its default unreachable while
  the audits still report it as reachable (this is how `get_up` lost `vigor`);
- **the same type tested twice in one method** — the second lesson can never fire (this is how
  `algebraic_analysis` sat behind `coin_eye` on the toll board);
- a lesson reached by one very specific branch — content one rename away from unreachable;
- any `ctx.Named(...)` left, and what it is matching.

For "can a player reach this at all", `dotnet run -- --mm-reach-csv` answers from the routes it can
enumerate — childhood, work, fight, and the swept lessons. The two files answer different questions
and neither replaces the other.
